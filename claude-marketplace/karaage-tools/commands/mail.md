# mail

Apple Mail.app を AppleScript 経由で操作する。ユーザーの依頼「$ARGUMENTS」を解釈し、下記ヘルパースクリプトの適切なサブコマンドを Bash で実行する。

```
HELPER="$HOME/Developer/dotfiles/claude-marketplace/karaage-tools/mail-helper.sh"
```

## 重要な制約

- **メールの送信は絶対にしない。** Claude ができるのは「読み取り・検索・下書き作成」まで。送信は必ず人間が Mail.app 上で確認して行う（ヘルパーにも送信機能は無い）。
- **下書き・返信を作成する前に、宛先・件名・本文の案をユーザーに提示して必ず確認を取る。** 承認を得てから作成する（誤宛先・誤送信の防止）。
- 初回実行時に「osascript（ターミナル）が Mail を制御することを許可しますか？」というダイアログが出る。承認が必要。誤って拒否した場合は「システム設定 → プライバシーとセキュリティ → オートメーション」で許可するようユーザーに案内する。
- `reply` は引用を保持するため本文をクリップボード経由でペーストする。初回は System Events の**アクセシビリティ権限**ダイアログが出る（「システム設定 → プライバシーとセキュリティ → アクセシビリティ」で許可）。実行中クリップボードを一時的に使い、終了時に元へ復元する。
- 対象は統合受信トレイ(inbox)。`read` / `reply` で使う `id` は `unread` / `recent` / `search` の出力に含まれる `ID:` の値を使う。

## ワークフロー

### メールを読む

```sh
"$HELPER" unread [件数]   # 未読一覧（既定20件）
"$HELPER" recent [件数]   # 最新一覧（既定20件）
"$HELPER" read <id>       # 指定メールの本文全文
```

一覧は `ID:/From:/Subject:/Date:/Snippet:` のレコード形式で返る。ユーザーには要点を日本語で要約して提示する。全文が必要なときだけ `read <id>` を使う。

### メールを検索する

```sh
"$HELPER" search "<キーワード>" [件数]
```

件名・差出人にキーワードを含むメールを返す（本文全文検索は重いため対象外。本文確認は `read <id>` で行う）。

### 新規下書きを作成する

1. 宛先・件名・本文をユーザーに提示し、承認を得る。
2. 本文を一時ファイルに書き出す（特殊文字・改行・日本語を安全に渡すため）。
3. ヘルパーに渡す。`save` で「下書き(Drafts)」に保存され、ウィンドウも開く。

```sh
BODY=$(mktemp /tmp/mail-body.XXXXXX)
cat > "$BODY" <<'EOF'
（本文をここに。ユーザー承認済みの内容）
EOF
"$HELPER" draft "to@example.com" "件名" "$BODY" "cc@example.com"   # cc は省略可
rm -f "$BODY"
```

宛先・cc はカンマ区切りで複数指定できる。

### 返信下書きを作成する

1. 元メールを `read <id>` で確認し、返信文案をユーザーに提示して承認を得る。
2. 返信本文を一時ファイルに書く。
3. ヘルパーに渡す。`reply` は引用付きの返信ウィンドウを開き、本文を引用の前にクリップボード経由でペーストする（アクセシビリティ権限が必要）。

```sh
BODY=$(mktemp /tmp/mail-reply.XXXXXX)
cat > "$BODY" <<'EOF'
（返信本文。ユーザー承認済みの内容）
EOF
"$HELPER" reply <id> "$BODY"        # 全員返信は末尾に all を付ける
rm -f "$BODY"
```

## 完了後

- 下書きを作成したら「Drafts に保存しました / 返信ウィンドウを開きました。Mail.app で確認し、問題なければ送信してください」と伝える。
- 一時ファイルは使用後に削除する。
